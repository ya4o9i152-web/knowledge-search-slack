# 従業員エンゲージメント調査 報告書（サマリ版）

**部署: 人事 / 客先: 製造業B / 作成: 2024年 / 機密度: 社外秘**

> 案件7（大規模RAG + Slack連携）の取り込み用サンプル文書です。実在の企業・案件とは関係ありません。

## 1. 調査概要

製造業B（従業員1,200名）の従業員エンゲージメント実態を、全社サーベイとインタビューで調査した。回答率は87%。

## 2. 主要な発見

- 総合エンゲージメントスコアは100点満点中62点で、業界平均（58点）をやや上回る
- 「上司との関係」は高評価（71点）だが、「キャリア成長の実感」が低い（48点）
- 入社3〜5年目の中堅層でエンゲージメントが最も低下する傾向

## 3. 課題分析

- 昇進・異動の基準が不透明で、中堅層が将来像を描けていない
- 研修制度はあるが、現場が忙しく受講できていない（受講率34%）

## 4. 提言

- キャリアパスの可視化（職種別のスキルマップ整備）
- 1on1 面談の制度化（月1回、上司向けトレーニング込み）
- 研修を業務時間内に組み込み、受講を上長評価に連動

## 5. 期待効果

- 中堅層の離職率を現状の12%から8%へ低減
- エンゲージメントスコア 62点 → 68点（2年計画）
