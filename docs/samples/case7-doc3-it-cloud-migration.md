# 基幹システム クラウド移行 報告書（サマリ版）

**部署: IT / 客先: 小売業C / 作成: 2023年 / 機密度: 社外秘**

> 案件7（大規模RAG + Slack連携）の取り込み用サンプル文書です。実在の企業・案件とは関係ありません。

## 1. プロジェクト概要

小売業Cのオンプレミス基幹システム（在庫・販売管理）を、AWS クラウドへ移行した。対象サーバー42台、データ総量18TB。

## 2. 移行アプローチ

- リフト&シフトを基本とし、移行後に段階的にマネージドサービス化
- 在庫DBは Aurora PostgreSQL へ、バッチ処理は ECS Fargate へ移行
- 移行は深夜帯に3回に分けて実施し、ダウンタイムを最小化

## 3. 成果

- インフラ運用コストを月額480万円から月額310万円へ（35%削減）
- バッチ処理時間が夜間6時間から2時間へ短縮
- 障害復旧時間（RTO）が従来の8時間から1時間へ改善

## 4. 課題と対応

- 移行初期にネットワーク帯域不足で同期が遅延 → Direct Connect 増設で解消
- 一部の old なバッチが文字コード依存で失敗 → 移行スクリプトで吸収

## 5. 今後の推奨

- マネージドサービス化のさらなる推進（自前管理のRedisをElastiCacheへ）
- コスト最適化のためのリザーブドインスタンス購入
