# 銀行A向け DX 推進提案書（サマリ版）

**部署: 戦略 / 客先: 地方銀行A / 作成: 2024年 / 機密度: 社外秘**

> 案件7（大規模RAG + Slack連携）の取り込み用サンプル文書です。実在の企業・案件とは関係ありません。

## 1. 案件概要

地方銀行Aの基幹業務におけるデジタルトランスフォーメーション（DX）推進を支援する。窓口業務のデジタル化と、行内データ活用基盤の構築を2フェーズで実施する。

## 2. 現状の課題

- 窓口handling時間が1件あたり平均18分と長く、来店客の待ち時間が課題
- 各支店の業務データがサイロ化し、本部での横断分析ができていない
- 紙ベースの稟議フローが意思決定スピードを下げている

## 3. アプローチ

- フェーズ1: 窓口タブレット導入と申込書のデジタル化（6ヶ月）
- フェーズ2: 全支店データを統合するデータレイク構築（12ヶ月）
- 行内人材のDXリテラシー研修を並行実施

## 4. ROI 試算

- 窓口handling時間 18分 → 9分（50%削減）により、年間およそ1.2億円の人件費削減効果
- ペーパーレス化で印刷・保管コスト 年間2,000万円削減
- 初期投資の回収期間は約2.5年と試算

## 5. 想定スケジュール・体制

- 総期間18ヶ月、コンサル4名 + 銀行側プロジェクトチーム6名
- 四半期ごとに経営層へ進捗報告
